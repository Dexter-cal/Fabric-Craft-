# Extra Project Notes

This file contains notes for features that are planned but not yet fully implemented in scenes.

## Saved Outfits
- User can save a combination of clothing items as a named outfit.
- This data should be stored locally or on the backend, associated with the user's account.
- A UI panel in the Wardrobe scene will allow loading and managing saved outfits.

## Follow System
- The backend needs to manage a 'followers' and 'following' list for each user.
- The UI in the Community Feed will show follow/unfollow buttons.
- A dedicated "social" or "profile" page could show follower stats.

## Reactions
- Beyond 'likes', users can react to posts with emojis (e.g., ❤️, 🔥, ✨).
- This will require a more complex data model on the backend to store reaction types and counts per post.
- The UI will show a small popup or bar to select a reaction.
